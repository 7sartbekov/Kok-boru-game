KÖK BÖRÜ RIDER
A browser game about kök börü, the Kyrgyz horseback game.

FILES
  index.html   the game
  anthem.mp3   the Kök Börü anthem (must stay in the same folder as index.html)

PLAY ON YOUR OWN COMPUTER
  Double-click index.html. It opens in your web browser.
  An internet connection is only needed for the fonts; the game works without it.

CONTROLS
  WASD or arrow keys   ride
  Shift                sprint
  Space or click       throw the ulak
  E                    grip and pull in a tug for the ulak
  P                    pause
  M / N                anthem / sound on and off

PUT IT ONLINE
  Upload both files together (or this whole folder as a zip) to a static
  website host such as itch.io, GitHub Pages or Netlify.
  The host must serve index.html as the main page.
